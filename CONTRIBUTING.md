# Contributing

1. Create a virtual environment and install: `pip install -e ".[dev]"`.
2. Run the checks before opening a pull request: `make all` (ruff, mypy, pytest).
3. Keep changes reproducible: seeds must be explicit, and any new reported number must be
   regenerated by a documented command (see `docs/REPRODUCIBILITY.md`).
4. Add or update tests for behavioural changes. Statistical claims need an interval or a paired
   comparison, not a single point estimate.
5. Describe limitations alongside results; do not extend claims beyond the evidence in the repository.

Bug reports should include the command, the package versions (`pip freeze`) and, where relevant, the
random seed.
